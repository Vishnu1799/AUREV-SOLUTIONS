# AUREV Brand Design Skill

Use this skill whenever designing or modifying visual elements, color schemes, typography, logos, or brand communications for AUREV SOLUTIONS.

## Brand Purpose
AUREV SOLUTIONS is an authentic, founder-led technology and innovation initiative led by Vishnu Prashanth S. (Founder & CTO). We engineer practical software, AI, automation, and hardware solutions.

## Color Tokens
```css
--color-navy: #10243A;       /* Primary deep navy */
--color-blue: #2457D6;       /* Corporate blue accent */
--color-warm-white: #FAFAF8; /* Dominant surface */
--color-light-grey: #F0F2F5; /* Secondary card surface */
--color-charcoal: #20252D;   /* Primary typography */
--color-muted-blue: #8DA8CC; /* Secondary metadata/borders */
```

## Typography System
- **Headings**: Manrope (geometric, architectural, clear)
- **Body**: Inter (highly readable, balanced)
- **Technical/Data**: JetBrains Mono (monospaced accents, tags, metrics)

## Brand Verification Checklist
- [ ] No claims of being an incorporated enterprise or holding physical campuses/labs.
- [ ] No generic AI stock imagery (robot brains, glowing circuits, neon grids).
- [ ] Logo is rendered as a clean, typographic wordmark (`AUREV SOLUTIONS` with subtle engineering badge).
- [ ] Tagline is accurately stated: *"Engineering Ideas Into Intelligent Solutions."*
