# AUREV UI/UX Engineering Skill

Use this skill to build, refactor, and review user interface components and layouts.

## Architectural Principles
1. **Premium Minimal Technology**: Editorial layout inspired by modern engineering publications and high-end industrial design.
2. **Generous Whitespace**: Allow content to breathe; avoid dense cramming.
3. **Structured Grids**: Align cards and text along an 8pt grid with disciplined `max-w-7xl` containers.
4. **Purposeful Motion**:
   - Subtly fade and lift cards on viewport entry (`y: 12px -> 0px, opacity: 0 -> 1`).
   - Micro-interactions on buttons, tabs, and filters (slight scale or border highlight).
   - Instant response without animation lag.

## Standard Component Roster
- `Header`: Sticky minimal navigation with backdrop blur, active route indicators, and mobile overlay.
- `Hero`: Architectural headline, concise mission statement, high-contrast CTA group, and custom geometric visual anchor.
- `ProjectCard`: Editorial card showing authentic status badge, category chip, problem summary, and key technical attributes.
- `StatusBadge`: Clean status indicator with color-coded dot and semantic typography.
- `FilterBar`: Category tabs and text search with instant, responsive filtering and clean reset.
- `Footer`: Minimalist tech footer with dynamic copyright, project links, and founder social links.
